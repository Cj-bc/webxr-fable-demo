# MR プレイルーム

WebXR の複合現実 (MR) 機能をひととおり試すためのサンドボックスです。Meta Quest 3 のブラウザを対象にしています。
自分の部屋の中で、機能ごとの「おもちゃ」を切り替えて遊べます。

## 起動

[Deno](https://deno.com/) 2 が必要です (Node.js は不要です)。

```sh
deno install     # 依存パッケージを取得
deno task dev    # 開発サーバーを起動
```

WebXR は HTTPS か localhost でしか動かないため、開発サーバーは自己署名証明書の HTTPS で起動します。

1. PC と Quest を同じネットワークにつなぎます。
2. 起動時に表示される `Network:` の URL (例: `https://192.168.x.x:5173/`) を Quest のブラウザで開きます。
3. 証明書の警告が出るので、「詳細設定」から続行します。
4. 「MR を開始」を押します。

床・壁・机を使う機能は、Quest の「スペースのセットアップ」が済んでいる部屋で動きます。
未設定の場合は、メニューの「部屋をスキャン」から呼び出せます。

そのほかのコマンド:

```sh
deno task build      # 型チェックと本番ビルド (dist/)
deno task typecheck  # 型チェックのみ
```

## 操作

素手 (ハンドトラッキング) とコントローラーのどちらでも操作できます。

| 操作 | 素手 | コントローラー |
|---|---|---|
| 道具を使う | つまむ (親指と人差し指) | トリガー |
| 近くの物をつかむ | 物の近くでつまむ | グリップ、またはトリガー |
| メニューを出す | 左手のひらを上に向ける | 左手のひらを上に向ける (コントローラーを外側へ倒す) |
| メニューを押す | 右手の人差し指で押す | 右のレイを当ててトリガー |

メニューは、左手のひらを上に向けている間だけ左手の上に出ます。左手が見つからないときは、正面に固定で表示されます。

### 道具

| 道具 | できること |
|---|---|
| ボール | 手の中に出して、離すと投げられる。現実の床・壁・机で跳ね返る |
| ブロック | 出して積める。両手でつかむと、手の間隔で拡大縮小、手の向きで回転 |
| 配置 | レイで指した面に物を置く。床や机には植物・ランプ・積み木、壁には絵。次回起動時も同じ場所に残る |
| お絵描き | つまんだまま (トリガーを引いたまま) 動かすと、空中に線が残る |
| ポータル | レイで指した壁や床に、別の世界が覗ける穴を開ける (3 つまで) |

### 手で写真を撮る

道具の選択に関係なく、素手のときはいつでも使えます (コントローラーでは使えません)。

1. 両手の親指と人差し指をそれぞれ L 字に開き、互い違いに向かい合わせて四角を作ります
   (片方の人差し指は上、もう片方は下向き)。その形を少し保つと、白い枠が出ます。
2. どちらかの親指を人差し指の付け根へ倒すと、枠の中に見えている範囲が写真になります。
3. 写真は枠の下に小さく浮かんで残ります。MR を終了すると、ページの「撮った写真」から保存できます。

枠は、人差し指を曲げる、前に向ける、手を下ろす、のどれかで消えます。

現実の景色も写すには、MR を開始する前に、ページの「カメラを許可」を押してください。
ボタンの下にカメラの映像が出るので、目の前の景色が映っていることを確かめます。
違うもの (アバターなど) が映っている場合は、その上の一覧から別のカメラを選びます。
許可しない場合は、仮想物体だけが暗い背景の上に写ります。

### 表示の切り替え

| 項目 | 内容 |
|---|---|
| 影 | 仮想物体の影を、現実の床や机に落とす |
| 遮蔽 | 現実の物や自分の手で、仮想物体を隠す |
| 遮蔽をぼかす | オン: 輪郭をなめらかに薄くする (チラつきが少ないが重い) / オフ: 画素ごとにくっきり隠す |
| 手で撮影 | 両手で作った枠で写真を撮る機能を有効にする |
| 部屋の形 | 検出された平面・メッシュと、その種類 (床、壁、机など) を表示する |
| 状態パネル | 各 WebXR 機能が有効か、いま何が取れているかを表示する |

「全部消す」は、おもちゃ・配置した物 (保存したアンカーを含む)・線・ポータルをすべて消します。

## WebXR の機能とコードの対応

機能ごとにファイルを分けてあります。どの API がどう使われているかは、各ファイルの冒頭のコメントから読めます。

| WebXR の機能 | 用途 | コード |
|---|---|---|
| `immersive-ar` セッション | パススルー映像の上に描画する | `src/app.ts` |
| 入力 (`XRInputSource`) | 素手とコントローラーを同じ形で扱う | `src/input.ts` |
| `hand-tracking` | 指先・手首の関節の姿勢を読む | `src/input.ts` |
| `plane-detection` / `mesh-detection` | 部屋の形の表示、物理の当たり判定、影を受ける面 | `src/features/room.ts` |
| `hit-test` | レイと現実の面の交点 | `src/features/hitTest.ts` |
| `anchors` (永続アンカーを含む) | 置いた物を現実の位置に固定し、次回も復元する | `src/features/placement.ts` |
| `depth-sensing` | 現実の物による遮蔽 | `src/features/occlusion.ts` |
| `light-estimation` | 現実の光源に照明を合わせる | `src/features/lighting.ts` |
| ハプティクス (`Gamepad.hapticActuators`) | つかむ・置く・押すときの振動 | `src/input.ts` の `pulse()` |

WebXR 以外で組み合わせているもの:

| 技術 | 用途 | コード |
|---|---|---|
| Rapier (物理エンジン) | ボールとブロックの物理 | `src/physics.ts`、`src/features/toys.ts` |
| ステンシルバッファ | ポータルの穴の切り抜き | `src/features/portal.ts` |
| Web Audio API (HRTF) | 衝突音などの空間音響 | `src/features/audio.ts` |
| キャンバステクスチャ | 空間内のメニューとパネル | `src/ui/canvasPanel.ts` |
| レンダーターゲット、`getUserMedia` | 手の枠で撮る写真 (仮想物体の描画と、パススルーカメラの映像の合成) | `src/features/handFrame.ts` |

## 構成

- `src/app.ts`: セッションの開始と、毎フレームの処理。機能は `Feature` として登録し、1 つが例外を出しても他は動き続けます。
- `src/tools.ts`: つまみ / トリガーの行き先 (メニュー → 近くの物をつかむ → 選択中の道具) を決めます。
- `src/features/`: 機能ごとの実装。メニューのボタンは各機能が自分で登録します。

## 制約

- Quest 3 のブラウザは、執筆時点で `light-estimation` に対応していません。その場合は固定の照明になります。
  対応状況は状態パネルで確認できます。
- 遮蔽は深度センサーの解像度と誤差の影響を受けます。現実の面に接している仮想物体は、縁が欠けて見えることがあります。
- 写真の中の現実の景色は、パススルーカメラの映像を仮の画角 (`handFrame.ts` の `CAMERA_FOV_HORIZONTAL`) で
  切り出しています。枠から見えた範囲と、位置や大きさがずれることがあります。
  また、写真には遮蔽が反映されません (現実の物の後ろにある仮想物体も写ります)。
- 永続アンカーには個数の上限があります。上限を超えた物は、そのセッション中だけ有効です
  (状態パネルに「保存失敗」として出ます)。
