# 掴む・選択する操作の候補

## ものを掴む・動かす

| 候補 | 動きと用途 |
|---|---|
| Rayで遠隔保持 | 手から出るRayで指し、つまむか握って保持する。棚の上の物を並べ直すときは命中時の奥行きを保つ。手元で使いたいときは、掴むと手元へ来る方式も候補。 |
| 腕を伸ばす（Go-Go） | 一定距離から仮想の手が実際の手より速く伸びる。少し遠い物にも手を伸ばして直接触れられる。 |
| 手招き | 手のひらで候補を指し、手首を引いて物を呼び、手元でキャッチする。 |
| 小さな世界（World-in-Miniature） | 片手に部屋の模型を出し、もう片手で模型内の物を動かして実物に反映する。 |
| 両手で範囲選択 | 両手で囲った範囲の物をまとめて持ち上げる。 |

## メニューや対象を選ぶ

| 候補 | 動きと用途 |
|---|---|
| 手のRay＋決定 | Rayが指している項目を強調し、pinchなどで確定する。 |
| 視線＋pinch | 視線で候補を決め、手元でつまんで確定する。視線追跡がない端末では頭の向きも候補。 |
| 親指と各指のタップ | 指の組み合わせに頻出操作を割り当て、必要なら指先にラベルを出す。 |
| 握って開く放射状メニュー | 握ってメニューを出し、手を動かして開くとその方向の項目を選ぶ。中心で開けばキャンセル。 |
| 候補を手元に集めてpoke | 手のひらで遠くの一群を指し、手元に並んだ候補から1つを直接押す。 |
